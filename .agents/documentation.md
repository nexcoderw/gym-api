# Documentation

## Standards

Update README, architecture, API conventions, security design, ADRs, and runbooks with behavior. Mark
implemented versus future work, include exact prerequisites/commands, database package interaction,
deployment shape, recovery, and entirely fictional Rwanda examples.

## Forbidden practices

No stale commands, undocumented endpoints, real personal data, credentials, vendor-doc copying, or
claims that unexecuted checks passed.

## Example and checklist

Document that liveness does not imply database readiness. Verify links, code parity, ownership,
security caveats, operations, and next steps.
